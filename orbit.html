Orbit

Year
2024
Role
Design System Engineer
Stack
TypeScript · React
Link
Live Site ↗

Orbit is a design system — tokens, components and documentation that keep an entire product team building the same way.

The problem was entropy: three products, four codebases, five shades of gray. I started from the ground up — a single source of truth for color, type, spacing and radius tokens — then built the component library on top: buttons, inputs, tables, modals, all typed, tested and documented.

Adoption was the real challenge, not code. I wrote the docs like a story, shipped codemods so teams could migrate without rewriting, and made every component accessible by default. Within a quarter, the design system was the default for new screens.

Fig. 01 — Component library

Everything is a token first. Designers change a value in one place and every product updates — no hunting through stylesheets, no drift between screens. The system makes the boring work boring, which is exactly what a good system should do.

Fig. 02 — Design tokens

Orbit taught me that consistency is a feature — and that the best way to scale a team isn't more rules, but better defaults.
