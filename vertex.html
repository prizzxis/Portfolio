Vertex

Year
2023
Role
Front-End Developer
Stack
HTML · CSS · JavaScript
Link
Live Site ↗

Vertex is a marketing site for a fast-growing SaaS — built to convert, built to rank, and built to load before the visitor blinks.

No framework, no build step, no bloat. I wrote the site in semantic HTML, modern CSS and a little vanilla JavaScript — which turned out to be the best performance decision of the project. Every page hits a perfect Lighthouse score, and the hero paints in under a second on 4G.

SEO was part of the build, not an afterthought: structured data, clean heading hierarchy, real content in the HTML and server-side rendering of every crawlable page. Within three months the site was ranking on the first page for its core terms.

Fig. 01 — Homepage

The team edits content through a lightweight CMS that generates static pages on publish. No database, no server to babysit — and nothing to break. I kept the build simple on purpose, because a marketing site that's painful to maintain stops being a marketing asset.

Fig. 02 — Page templates

Vertex is proof that the web still rewards restraint: fewer dependencies, smaller payloads, and copy and code that pull in the same direction.
