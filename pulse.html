Pulse

Year
2024
Role
Front-End Developer
Stack
React · TypeScript · Node.js
Link
Live Site ↗

Pulse is a SaaS analytics platform for product teams — dashboards that make dense data feel calm instead of overwhelming.

The hard part wasn't the charts — it was restraint. I built a component system where every visualization shares one visual language: a single type scale, a strict grayscale palette, and consistent empty and loading states. Data reads clearly, and motion guides the eye instead of distracting it.

Behind the scenes, Pulse processes thousands of events per day through a Node.js API. I owned the front end end-to-end: real-time updates over WebSockets, virtualized tables for large datasets, and an accessibility pass that made every chart navigable by keyboard.

Fig. 01 — Landing page

Motion was used sparingly but deliberately. GSAP's ScrollTrigger drives the narrative on the marketing site, while in the app itself every transition shares a single easing curve — so the product feels cohesive, predictable, alive without being noisy.

Fig. 02 — Analytics dashboard

The most satisfying fix was invisible: replacing a janky table re-render with a virtualized list cut interaction lag from 200 ms to under 16 ms. Users didn't notice — and that was exactly the point.
