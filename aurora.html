Aurora

Year
2025
Role
Front-End Developer
Stack
HTML · CSS · JS · GSAP
Link
Live Site ↗

Aurora is a real-time analytics dashboard designed to make complex data feel calm. My focus was the front end: architecture, motion and performance.

The client needed a tool their team would actually enjoy using. That meant obsessive attention to load time, interaction latency and the small moments — hover states, chart transitions, empty states — that turn software into craft.

I built a component system from scratch, tuned every animation to a shared easing curve, and shipped a Lighthouse-verified 98+ performance score. The result: a 40% drop in time-to-interactive and a dashboard people describe as "smooth".

Fig. 01 — Dashboard overview

Motion was used sparingly but deliberately. GSAP's ScrollTrigger drives the page narrative on marketing pages; in the app itself, every transition shares one easing curve so the interface feels cohesive and predictable.

Fig. 02 — Interaction details

Performance work went beyond tooling: aggressive code-splitting, SVG-based visuals, and a strict budget for third-party scripts. Core Web Vitals are green across the board, including on mid-range mobile devices.
